# 页边 · 课程阅读器

打开「采样与混叠」，划出一句话，点 **解释一下** 或 **翻译选区**。要问图，先点 **框选图片**，拖出图和图例，再发问。按 **Esc** 可以取消选区；正在生成的回复不会中断，已有讨论仍可从右栏下拉框找回。点 **定位原文** 回到对应位置。

提问框旁的 **模型** 和 **思考强度** 也适用于快捷翻译与解释。服务端用本站 API 项目密钥查询官方模型列表，仅展示与已核对的 Responses 文字／图片讲解目录相交的型号（含 GPT-6.2、Terra／Luna、mini／nano 等），强度随模型变化。默认仍为 GPT-5.4 mini、低强度；若项目未列出 mini，则选择列表内型号。修改从下次提问起生效，当前浏览器会记住选择。列表查询受限时明确标记“待核实”，保留文档目录供尝试；查询成功但无兼容型号时不可发问。模型列表不保证实时配额或推理调用成功，调用错误会保留问题。官方已弃用的 nano 会单独标注。

**速度**独立于思考强度。项目默认沿用 API 项目设置；选「标准」则明确请求标准档。支持的模型还可手动选加价的 Fast 或 Ultrafast。回复旁显示 API 返回的实际档位；请求加速不保证获得加速。

**导入讲义**支持带文字层的 PDF、扫描 PDF（框选）及常见静态 PPTX，每份最多 20 MiB。旧式 PPT、需要密码或版式复杂的课件请先导出 PDF。原件不发给模型。发问时只发送当前选区、问题、本线程必要上文和本课程的相关旧讨论。

在阅读器上方输入目标页码，按 Enter 或点「跳转」；底部滑条可从第一页拖到最后一页。PDF 和 PPTX 用法相同。

电脑上可左右拖动讲义两侧的分隔线，分别调整资料库或讨论栏宽度，当前浏览器会记住列宽；双击分隔线恢复默认。手机上仍在讲义与讨论之间切换。

### 本机运行

需要 Node 22.13+。在项目目录运行：

```sh
npm ci
npm test
npm run build
# 首次初始化本地数据库，只执行一次；新迁移按顺序执行。
for migration in drizzle/*.sql; do
  node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file "$migration" || break
done
PAGEWISE_KEY_FILE=/absolute/path/to/private-key-file npm run dev:key -- --port 5183
```

访问 [本机阅读器](http://127.0.0.1:5183/signin-with-chatgpt?return_to=/)。本地登录是 Sites 提供的测试身份，不是线上登录；服务只应监听回环地址。只验收阅读和记录时用 `npm run dev -- --port 5183`，无需密钥。键文件仅包含密钥文本；不要提交、截图或复制到前端。运行脚本只把值交给本机预览的服务端进程，不创建密钥副本。

### 数据与部署

- Sites 的登录身份决定每条数据库查询的所有者；课程名用于划分该用户的记忆，不是权限边界。相同账号在同一站点读取同一套资料。本地与线上数据库独立。
- D1 保存资料索引、页码、归一化选区、问答和引用；R2 保存原件和截图。删除讨论同时清理其图片与记忆引用，删除讲义清理所属讨论。既有回答是当时的解释，不随引用删除而重写。
- 讨论会保留，但不一定被引用。只在本人同课程的近期已答讨论中匹配选区主题；纯图片讨论可按具体提问匹配。通用提示、助手回复和英文虚词不作为主题证据。匹配不足就不引用，最多三条，可点击回看。历史讨论也会重新筛选原有引用，不改写旧回答。
- 服务端按本次选择的模型和强度调用官方 Responses API，发送文本及选区图片，`store:false`。没有把整份课件提供给模型的工具。密钥或配额出错时保留问题并提示，不生成模拟回答。
- 站点复用 `.openai/hosting.json` 中的项目 ID，绑定 `DB`、`BUCKET`。本站使用名为 `hts01` 的 Sites Secret；轮换密钥时更新同名 Secret，再部署使之生效。本机仍用 `OPENAI_API_KEY`。本地预览的模拟身份只在本地开发服务中启用。

测试分别覆盖真实 SQLite 上的所有者隔离、图片权限、选区与对话持久化、记忆/删除，Responses 请求和异常，以及前端讨论状态与选区坐标。运行 `npx tsc --noEmit` 检查类型。开发时遵循先红后绿，服务端及 UI 测试不消耗模型额度。

### 笔记本

顶部和首页项目导航中的 **笔记本** 展示当前账户的全部笔记，可按项目、对话或编号、标题、正文搜索。在阅读右栏切到 **笔记本**，可以一边看讲义一边编辑。

讲义选区、单轮回答和整段讨论都通过 **存入笔记** 对话框保存。先核对内容预览与原文页码，再选择 **新建笔记** 或 **追加到已有笔记**。追加只在正文末尾添加内容，不替换已有正文、标题和编号。保存成功会显示目标笔记的编号和标题；失败时保留保存意图并提供重试。

每条笔记自动分配编号，编号可改为其他正整数，同一账户内不重复。对话里的 **新建笔记** 用于创建空白笔记。**关联已有笔记** 只添加对话来源，不自动复制问答正文。可以把其他项目的对话关联到同一条笔记，也可在编辑器里手动添加项目或对话来源。

修改会自动保存。不同笔记分别保留草稿；其他窗口更新同一条笔记时，会提示先导出当前编辑再合并。项目改名和资料移动会更新来源；删除对话或资料会保留笔记正文和来源描述。旧版的统一正文会迁入 **原学习笔记**，旧版窗口的保存也继续校验版本。

笔记数据库使用 `drizzle/0007_study_notebooks.sql`。追加保存还依赖 `drizzle/0008_note_append_writes.sql`，以记录每次追加的请求 ID。相同请求重试不会重复添加，即使期间发生过其他追加；同一请求 ID 改变内容会被拒绝。台账随笔记保留，删除笔记时一起清理。

发布时先在同一 D1 上按顺序应用迁移，再发布新代码。未完成 0008 升级时，新代码会明确拒绝追加并返回 503，不写入部分正文或误报保存成功。已有笔记的读取仍可继续。

首页的 **搜索资料库** 覆盖问题、回答、讲义摘录与笔记，并显示匹配片段和来源。**复习** 按已保存资料、页码和讨论组织内容，不编造章节或掌握状态。**自测** 会打开一个未发送的问题草稿，由你核对材料与报价后发送；它不会自动调用收费模型。

### 站点模型费用

站点使用 OpenAI 回传的实际 token 和实际处理档位，按[官方单价](https://developers.openai.com/api/docs/pricing)核价。账单记下费率版本和各项 token 用量。每 0.01 美元折合 1 积分，问答合计后四舍五入到 0.001 分。失败的操作不扣分。单次问答上限为 4 分，单批记忆整理上限为 1 分，可用余额更低时以余额为限。超出上限的费用由站点承担。Magpie 与个人 API 使用各自的额度。

### 自带 API
打开 **模型来源**，填写服务商的公网 HTTPS Base URL 和自己的 API Key。可选择 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 或 Gemini generateContent。读取模型列表后点击需要的型号，或手填模型 ID。保存后，提问框只列出你选中的型号，解释、翻译、追问都使用本次所选模型，不自动回退到站点密钥。

- **测试连通**读取模型列表；列表接口成功不等于所选模型可推理，列表接口受限也不一定妨碍提问。
- **检测协议**用所选型号分别试发短问题。**测试模型**只验证所选协议；也可逐个测试勾选的型号。生成请求按服务商规则计费，不会附上讲义或课程记忆。
- **图片能力按型号记录**。保存时用随机色卡测试默认型号一次；其他已选型号可以单独测试。只有答对色卡的型号才启用框图。
- 密钥默认遮蔽，读取配置不带密钥。点眼睛可显示再隐藏；只有本人主动查看时才取回本人已存的密钥。切换 Base URL 要重新输入密钥，不会把旧密钥转给新地址。可随时切回站点默认或移除配置。

重新打开页面后默认使用站点模型，可在模型来源中重新启用已保存配置。
本机开发预览仅连接已知公网服务商；其他自定义公网 HTTPS 域名使用托管 Sites 版，不连接本机或内网模型。

### 登录与管理员

公开入口是 `/login`。阅读器、资料、问答、笔记和积分接口使用服务端验证后的身份。现有 ChatGPT 登录使用原有的用户 ID。通过管理员指定的身份服务登录时，新账号会创建独立资料库。已有用户先通过 ChatGPT 登录，再在「登录方式」中绑定外部账号。

- `PAGEWISE_LEGACY_EMAILS` 保存仍可通过 ChatGPT 登录的邮件地址，逗号分隔。通过此通道进入的用户继续访问原有资料。
- `PAGEWISE_ADMIN_EMAILS` 保存可操作「个人账户 → 积分管理」的原有 ChatGPT 账户。管理员调分会留下金额、原因、操作人和时间，并计入用户收支明细。
- Google 和 GitHub 直连各自的 OAuth 服务。Google Web 应用客户端回调为 `https://pagewise.htsjustin.com/api/auth/callback`，GitHub OAuth App 回调为 `https://pagewise.htsjustin.com/api/auth/callback/github`。在 Sites 服务端设置 `SITE_AUTH_ORIGIN=https://pagewise.htsjustin.com`、`GOOGLE_CLIENT_ID`、`GITHUB_CLIENT_ID`，把 `GOOGLE_CLIENT_SECRET` 和 `GITHUB_CLIENT_SECRET` 存为 Secret。
- 邮箱验证码由 Resend 发信。先验证一个发信域名，例如 `auth-mail.htsjustin.com`，再把发件地址设为 `AUTH_EMAIL_FROM`，并把发送权限的 `RESEND_API_KEY` 存为 Secret。发布时应用 `drizzle/0009_email_login.sql`。验证码在同一浏览器内有效 10 分钟，最多尝试 5 次，成功后不能重用。
- 原有用户先用受邀的 ChatGPT 账号登录，再从账号页面绑定 Google、GitHub 或邮箱。外部身份用提供方和稳定的身份 ID 查找原资料库。邮箱地址相同不会自动合并账号。


### GitHub 与正式站

本仓库包含页边阅读器的页面、服务端、数据库迁移、测试和静态资源。提交发布前可运行 `npx tsc --noEmit`、`npm test` 和 `npm run build`。

正式站由 ChatGPT Sites 发布。发布 GitHub 变更时，在 Codex 中指定 GitHub 仓库和提交，请它把该提交同步到现有「页边 · 学习阅读器」项目的 Sites 源码仓库，构建、保存版本并部署。发布请沿用当前项目及 D1、R2 绑定。生产配置和用户数据保存在 Sites，服务端环境变量在 Sites 后台管理。
